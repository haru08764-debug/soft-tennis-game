# GLB model assets (v1.10.0)

The game loader expects these files in this directory:

- `tennis_court.glb` — the uploaded court model
- `tennis_racket.glb` — the uploaded racket model

Upload both binary GLB files here using GitHub's **Add file → Upload files**. Keep these exact filenames; `index.html` loads them from `./assets/`.

The game falls back to its built-in court and racket if either model fails to load.

Before redistributing the game, include the original creator attribution required by each model's CC BY 4.0 listing.
